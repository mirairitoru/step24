## アプリ概要
保護動物と里親希望者をつなぐマッチングサービスです。

里親希望者は保護動物を検索し「興味あり」を送りマッチしたらチャットできます。
保護団体は承認後はチャットでのやり取りで譲渡まで行う

## 使用技術
・PHP 8.3
・Laravel 13
・PostgreSQL
・Laravel Breeze
・Docker Sail/WSL2
